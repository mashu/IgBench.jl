IgBench.jl

Extensible V(D)J benchmark harness. Use as a library from IgFormer (or any client) via run_suite, or standalone via scripts/run_bench.jl.

IgBLAST.jl is the only built-in tool package dependency. SwiftIG and IgFormer register through SwiftIGAnnotator / CallableAnnotator.

Installation

using Pkg
Pkg.add(url="https://github.com/mashu/IgBench.jl")

Library (embedded)

using IgBench

suite = suite_from_manifest(manifest, tools)
result = run_suite(suite;
                   mode = DiagnosticMode(max_sequences = 256),
                   store = DirectoryRunStore("runs/diagnostic/1000"),
                   step = 1000, tags = (; epoch = 3))
# result.metrics is in-memory for logging; store optional (nothing / NullRunStore)

Data

Describe cohorts with DatasetManifest: SimSource (IgSim gold) and AirrSource (real AIRR). species is a free string — never hardcoded.

Pass cache = PanelCache("cache/run") to run_suite so diagnostic steps reuse the same frozen sequences.

Modes

ModeUse
DiagnosticModeMid-training: small N, light timing, predictions off by default
FullReportModeEnd report / CI: full N, timings, predictions + summary.md
