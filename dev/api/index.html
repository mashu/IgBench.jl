IgBench.IgBench — Module
IgBench

Extensible VDJ benchmark harness: pluggable annotators, metrics, and panels. Library-first API (run_suite); optional standalone scripts/run_bench.jl. IgBLAST.jl is the only built-in tool package dependency — SwiftIG / IgFormer plug in via SwiftIGAnnotator / CallableAnnotator.
